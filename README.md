# scout-filters

Форма фильтров для бота-скаута Vinted. Одна страница, ничего больше.

Открывается из самого бота командой `/app` как Telegram Mini App. Данные
о фильтре бот кладёт прямо в адрес кнопки, а сохранение уходит обратно
боту через Telegram (`sendData`) — страница никогда не обращается к
компьютеру владельца, и поэтому ей не нужен ни тоннель, ни сервер.

Секретов здесь нет и быть не может: только разметка и скрипт. Фильтры на
GitHub не попадают — они едут в адресе, который открывает Telegram.

Исходник живёт в приватном репозитории бота, файл `miniapp.html`. Здесь
лежит его копия, потому что GitHub Pages работает только на публичных
репозиториях.

## Обновление

    cp ../files/miniapp.html index.html && git commit -am "обновление формы" && git push
